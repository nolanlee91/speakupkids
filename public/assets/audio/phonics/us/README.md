# Production phoneme recordings

Place verified General American phoneme clips in this directory.

The first recording set should cover these grapheme/audio keys:

`s, a, t, p, i, n, m, d, g, o, c, k, e, u, r, h, b, f, l, j, v, w, x,
y, z, qu, sh, ch, th, ck, ng, ll, ss, a-e, i-e, o-e, u-e`

Recommended file names:

`<key>.mp3`, for example `s.mp3`, `sh.mp3`, and `a-e.mp3`.

Sight words in Unit 10 should continue using whole-word speech, not isolated
phoneme clips.

Do not enable these files in the UI until every clip has passed the recording
and teacher-verification rules in
`public/assets/images/phonics/README.md`.
